# FlipClock

A modern, animated flip clock built with **HTML, CSS, and vanilla JavaScript**. Inspired by classic split-flap clocks, it combines a realistic flipping animation with a customizable interface.

## Features

- **Animated clock display** — split-flap-style transitions for changing digits.
- **Live clock** — displays the current local time.
- **Fixed-time mode** — set a custom time and watch it advance.
- **12-hour and 24-hour formats** — switch between time formats.
- **Seconds toggle** — show or hide seconds.
- **Time editor** — set a custom hour, minute, and AM/PM period.
- **Fullscreen mode** — expand the clock to fill the screen.
- **Keyboard shortcuts** — access controls quickly.
- **Persistent settings** — saves preferences using browser localStorage.
- **Responsive layout** — adapts the interface to different screen sizes.

## Getting Started

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/favaz-am/FlipClock.git
   ```

2. Open the project directory:

   ```bash
   cd FlipClock
   ```

3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No build step or package installation is required.

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `H` | Show or hide the settings panel |
| `F` | Toggle fullscreen |
| `T` | Open the time editor |
| `Esc` | Close the editor or exit fullscreen |
